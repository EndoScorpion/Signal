=== EA v2.4 SPEC SUMMARY (for /app_addons implementation) ===

INSTRUMENT: EURUSD, FXOpen ECN 5-digit, H1 bars (UTC server time)
COST MODEL: 0.00008 round-trip per trade (8 ECN points), $0.10/pt at 0.1 lot

INDICATORS REQUIRED:
  EMA50 (H1): ema50, ema50_slope=(ema50-ema50.shift5)/ema50.shift5, accel=slope-slope.shift5
  ATR14 (H1): atr, atr_rank=rolling 252-bar pct rank
  H4 EMA50: resample H1 close to 4H, apply EMA50, compute h4_dist_atr=(ema4-price4)/atr4h
  EMA5, EMA13 (H1): alligator_spread=(ema13-ema5)/atr
  lo_n: min(low[-1:-10]) (10-bar low of previous bars)
  lo10_break: close < lo_n
  consec_lo10: rolling 5-bar sum of lo10_break
  monthly_slope: mean(ema50_slope) for current calendar month
  annual_slope: (ema50.last - ema50.first) / ema50.first for current calendar year

SIGNAL 1 (S1): SHORT at 13:00 and 14:00 UTC (H1 bar close)
  CONDITIONS:
    atr_rank < 29
    h4_dist_atr >= 1.0  (price >= 1x ATR below H4 EMA50)
    ema50_dist >= 0.5   (price >= 0.5x ATR below H1 EMA50)
    qc_score >= 3       (sum of: lo10_break, hi5_break, body_atr>0.3, ema50_dist>0.3, atr_rank>20)
    body_atr <= 1.5     (signal candle not spike)
    lo10_break = True   (current bar breaks below 10-bar low)
    ema50_accel <= 0    (bearish acceleration)
    annual_slope <= 0   (bearish annual regime)
    Same-day dedup: first qualifying bar per day only (skip 14:00 if 13:00 fired)
  EXIT:
    Stop: entry + 1.5 * atr14
    Target: entry - 1.5 * atr14
    MaxHold: 5 bars (close at bar 5 if no stop/target hit)
  SIZE MODEL (per trade):
    base: accel<=-0.0002→1.3x | <=-0.0001→1.2x | <=-0.00005→1.1x | else→1.0x
    + alligator_spread>0.5: +0.2x
    - alligator_spread<0.3: -0.1x
    + consec_lo10>=2: +0.1x
    + monthly_slope<0: +0.1x / monthly_slope>0: -0.2x
    floor: 0.5x

SIGNAL 2 (S2): SHORT at 08:00 UTC (H1 bar close)
  CONDITIONS:
    atr_rank < 29
    h4_dist_atr >= 1.0
    ema50_dist >= 0.5
    qc_score >= 3
    body_atr <= 1.5
    lo10_break = True
    ema50_accel > 0     (local exhaustion/bounce)
    monthly_slope < 0   (bearish monthly context)
  EXIT:
    Stop: entry + 1.5 * atr14
    Target: entry - 1.5 * atr14
    MaxHold: 4 bars
  SIZE MODEL:
    alligator_spread > 0.3 → 1.2x
    alligator_spread 0.1-0.3 → 1.0x
    alligator_spread < 0.1 → 0.8x
