# Nasif's working preferences

- End every reply with a message counter (he restarts chats every 15 messages) and a usage estimate.
- Occasionally offer a .txt notepad backup of important code, and include one for code you add.
- Visual apps: deliver a full artifact preview (.html rendered in the side panel), not an inline widget.
- Theme: black background #000000, neon green text #39ff14, hacker/terminal look. Google Sheets: Times New Roman, dotted neon-green gridlines, keep a white template copy.
- He runs the app as a local file in Chrome on Windows and wants it to work on any browser, tablet, phone, online and offline.
- Ask before heavy work on uploaded HTML containing SVG: grep first, offer to preview only the SVG parts.
- Trading results: backtested wins are not guarantees; point him to out-of-sample and forward-test numbers.
