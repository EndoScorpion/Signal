# Job tracker artifact conventions

- Style: black background, neon green #39ff14 text, Times New Roman. Accent colors: pink L1 list, yellow borderline, violet AI section, cyan discovery log.
- Resume job-history format: "Job title - Employer" bold (one size bigger), then italic "via contractor - location - arrangement - dates" on the same line; Times New Roman 12; contractor names come from the second (main) resume. Applies to page, thumbnails and PDF/DOCX/HTML exports. Export thumbnails sit in the right column outside the document. Names centered.
- Never remove a visual or feature (full-document live text edit, thumbnails, index, sortable tables) without asking first.
- Index: collapsible color-coded groups; each group header is also a link to its first section. Add a new group for each new major section, keep Tampa Bay and Panhandle grouped, and list counts per type in the index when asked.
- All tables sort by clicking a header and support ranked multi-column sorting; empty values sort last.
- Before editing: copy the source to a dated backup. After editing: run a headless-browser check for page errors, then republish to the same artifact URL. Offer a .txt backup of important code occasionally.
- Pasted job posts: follow the job-post-skill-extraction skill. Searches for more posts: follow the job-search-discovery skill.
- Keep replies short and end each with a usage/credit estimate (the user is budget-conscious).
