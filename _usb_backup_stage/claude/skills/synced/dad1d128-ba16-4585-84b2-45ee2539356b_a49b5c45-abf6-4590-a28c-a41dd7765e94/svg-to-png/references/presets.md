# Preset Reference

## app-icon
iOS/Android app icon sizes. Auto-applies white background (required for iOS).
- 1024×1024, 512×512, 256×256, 128×128, 64×64, 32×32

## favicon
Web favicon sizes. Transparent background by default.
- 256×256, 128×128, 64×64, 32×32, 16×16

## splash-portrait
iOS splash screen portrait sizes.
- 1284×2778, 1170×2532, 1125×2436, 828×1792, 750×1334

## splash-icon
Single Expo splash image (referenced by splash.image in app config).
- 1024×1024

## og-image
Open Graph social preview image.
- 1200×630
