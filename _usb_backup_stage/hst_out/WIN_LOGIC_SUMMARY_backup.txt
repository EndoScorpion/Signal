WIN_LOGIC_SUMMARY.txt  (EURUSD MT4 EA, Strong2010b_claude b32-b36)  2026-10-11

1) WIN LOGIC (plain words)
- The EA SELLS. Sells win most in CHOPPY, sideways, weak-trend markets.
- Sells lose most when price trends hard, moves efficiently, or the day's range is already big.
- So every gate does one job: SKIP a sell when the market is trending,
  high efficiency ratio (ER), high ADX, stretched (high z-score), or wide daily range.
- All gates are OFF by default. Turn one on with its Use...=1 input or a .set preset.

2) HOW THE BRANCHES WERE FOUND
- Analysed 485 real sells (Aug 2025 to Sep 2026): wins vs losses per indicator.
- Real MT4 backtests 2017-2021 for the proven gates (z-score, daily range).
- Swept every candidate over periods 2 to 500 bars and timeframes M1 to H4.
- Stability check: a setting must work in BOTH first half and second half of the data.
- Rule: a gate is rejected only after the full sweep + stability check.
- Bred/combined winners (e.g. chop + z-score) and kept combos that added profit.

double Chop33(int n){ int tf=ChopTF; double s=0; for(int i=1;i<=n;i++){ s+=iATR(Symbol(),tf,1,i); } double hh=iHigh(Symbol(),tf,iHighest(Symbol(),tf,MODE_HIGH,n,1)),ll=iLow(Symbol(),tf,iLowest(Symbol(),tf,MODE_LOW,n,1)); if(hh-ll<=0){ return(100); }
   return(100.0*MathLog10(s/(hh-ll))/MathLog10(n)); }

C) Daily range filter  [Strong2010b_claude_b36.mq4]
bool FilterDailyRangeExpansion(){ if(UseDailyRangeFilter!=1){ return(true); }
   double dAtr=iATR(Symbol(),PERIOD_D1,RangeAtrPeriod,1); if(dAtr<=0){ return(true); }
   int n=iBarShift(Symbol(),PERIOD_M15,iTime(Symbol(),PERIOD_D1,0)); if(n<1){ return(true); }
   int hb=iHighest(Symbol(),PERIOD_M15,MODE_HIGH,n,1), lb=iLowest(Symbol(),PERIOD_M15,MODE_LOW,n,1); if(hb<0 || lb<0){ return(true); }
   return(iHigh(Symbol(),PERIOD_M15,hb)-iLow(Symbol(),PERIOD_M15,lb) <= dAtr*MaxRangeAtrMultiplier); }

D) Low ADX + CCI floor gates  [WinGates_b36.mqh]
extern bool   UseAdxLowGate=0;    // sell only in a weak trend: ADX(AdxPer) on AdxTF <= AdxMax   (sweep M5/150 -> 299, <= 7.6)
extern int    AdxTF=5;
extern int    AdxPer=299;
extern double AdxMax=7.6;
bool Gates36(){
   if(UseAdxLowGate==1 && iADX(Symbol(),AdxTF,AdxPer,PRICE_CLOSE,MODE_MAIN,1)>AdxMax){ return(false); }
   if(UseAdxSlopeGate==1 && iADX(Symbol(),AdxSlTF,AdxSlPer,PRICE_CLOSE,MODE_MAIN,1)-iADX(Symbol(),AdxSlTF,AdxSlPer,PRICE_CLOSE,MODE_MAIN,4)<AdxSlMin){ return(false); }
   if(UseCciFloorGate==1 && iCCI(Symbol(),CciFTF,CciFPer,PRICE_TYPICAL,1)<CciFMin){ return(false); }
   return(true); }
