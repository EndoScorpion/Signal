# Setup — Claude Phone Keyholder Bot\n\n## What Nasif needs to do (5 steps)\n\n### 1. Create Telegram bot\n1. Open Telegram → message **@BotFather**\n2. Send `/newbot`, pick a name + username (e.g. `MyKeyholderBot`)\n3. Copy the **token** it gives you → this is `TELEGRAM_TOKEN`\n\n### 2. Get your Telegram user ID\n- Message **@userinfobot** on Telegram → it replies with your numeric user ID\n- This goes in `ALLOWED_USER_IDS` — only you can command the bot\n\n### 3. Get API keys\n- **Anthropic key**: https://console.anthropic.com → API Keys → Create key → `ANTHROPIC_KEY`\n- **GitHub token** (optional, for board writes): https://github.com/settings/tokens → Fine-grained token → repo read+write on EndoScorpion/signal-board → `GITHUB_TOKEN`\n\n### 4. Add deploy key to signal-board (optional, for SSH push)\n- The public key is in `keyholder-bot/deploy_key.pub`\n- Go to https://github.com/EndoScorpion/signal-board/settings/keys → Add deploy key\n- Title: `keyholder-bot-deploy`, paste the pub key, check Allow write access\n- Save private key to `~/.ssh/keyholder_deploy` (copy from coordinator on request)\n\n### 5. Enable GitHub Pages (if not already on)\n- Go to https://github.com/EndoScorpion/signal-board/settings/pages\n- Source: Deploy from branch → `gh-pages` → `/` → Save\n\n### 6. Deploy (pick one)\n\n#### Option A: Run on laptop (simplest)\n```bash\ncd Signal/keyholder-bot\npip install -r requirements.txt\ncp .env.example .env\n# Edit .env with real values\npython bot.py\n```\nRegister as Windows Task Scheduler task (onlogon, hidden) to keep it running.\n\n#### Option B: Railway (free, cloud)\n1. Go to https://railway.app → New Project → Deploy from GitHub\n2. Point at EndoScorpion/Signal, root directory: keyholder-bot\n3. Add env vars in Railway dashboard\n4. Done — Railway keeps it running 24/7\n\n#### Option C: Render (free tier)\nSame as Railway. https://render.com → New Web Service → set env vars.\n\n### 7. Test\n- Open Telegram, find your bot by username\n- Send: `status` — bot replies via Claude\n- Send: `read board` — Claude reads last 3 signal-board entries\n- Send: `post WP/t=+12pts n=5 #StackC` — posts vague update to board\n\n## Security checklist\n- [ ] .env is in .gitignore ✓ (already set)\n- [ ] ALLOWED_USER_IDS is set (without this, anyone can command the bot)\n- [ ] Bot token never appears in code or logs\n- [ ] GitHub token has minimum permissions (only signal-board write)\n
