**Conclusion:** Filter never triggers on valid setups. **Permanently rejected as incompatible with v2.3 entry criteria.**

## Interpretation

With 31 qualifying FXOpen trades over 3 years, any single filter that splits n≥30 into two groups will have n<20 in each group. The **only path to adoption** is either:
1. More FXOpen data (2027–2028) to grow n
2. A filter that is ADDITIVE (increases n by relaxing a condition)
3. Combination with a different asset class or instrument

The v2.3 strategy is well-optimized for the current dataset. Future improvements depend on data accumulation, not further parameter search.
